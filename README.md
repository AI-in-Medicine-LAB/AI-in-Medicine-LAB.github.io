# AIMLab website

Official website of the AI in Medicine Lab (AIMLab), Institute of Intelligent Bioelectrical Engineering,
National Yang Ming Chiao Tung University.

Live at https://ai-in-medicine-lab.com/

## Authors

- **Meng-Ching Chen** ([@Chen-MouChin](https://github.com/Chen-MouChin)): site design and development,
  covering architecture, frontend, program pages, the rPPG demo and visuals.
  Source build: https://github.com/Chen-MouChin/aimlab-site-preview
- **Hsu-Cheng Wu** ([@wuxuchengee14](https://github.com/wuxuchengee14)): admin panel and content server,
  co-developed with Meng-Ching Chen.

## Updating content

Edit only the data files under `assets/data/` (news, people, programs, publications, highlights, site).
Every other file is replaced when the authors publish a new version of the site.
